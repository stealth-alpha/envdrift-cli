# Contributing

Thanks for looking under the hood.

- **Runtime:** Node 18+. The package has **zero runtime dependencies** by
  design — please do not add any without discussing first.
- **Tests:** `npm test` (runs `node --test`). CI runs the same suite on Node
  18 and 20; PRs should keep it green.
- **Style:** small focused PRs; include a test for behavior changes.
- **License:** MIT. By contributing you agree your contributions are
  licensed under the repository's MIT license.
